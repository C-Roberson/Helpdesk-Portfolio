# 📜 Google IT Support Professional Certificate

* **Credential Provider:** Coursera
* **Status:** Completed September 2026

## 🔍 Program Overview
The Google IT Support Professional Certificate is a rigorous, hands-on training program designed to build foundational expertise in information technology and help desk operations. The curriculum focuses heavily on real-world troubleshooting, customer service methodologies, system administration, and infrastructure security.

## 📚 Core Curriculum Breakdown
The certification consists of six comprehensive courses covering the full spectrum of entry-level IT support responsibilities:

1. **Technical Support Fundamentals**
   * Introduction to computer hardware assembly, binary code, operating systems, and software architecture.
   * Core troubleshooting methodologies and IT customer service best practices.

2. **The Bits and Bytes of Computer Networking**
   * Comprehensive study of the 5-layer network model and TCP/IP protocol suite.
   * Practical application of core networking services including DNS, DHCP, IP addressing, and subnetting.
   * Troubleshooting network performance and connectivity issues.

3. **Operating Systems and You: Becoming a Power User**
   * Deep dive into Windows and Linux administration.
   * File system navigation, process management, user account provisioning, group permissions, and software management via GUI and command-line interfaces (Bash and PowerShell).

4. **System Administration and IT Infrastructure Services**
   * Enterprise server and infrastructure management, including Active Directory concepts and user management.
   * Cloud infrastructure services, data backups, and disaster recovery strategies.

5. **IT Security: Defense Against the Digital Dark Arts**
   * Core security principles: Authentication, Authorization, and Accounting (AAA).
   * Encryption algorithms, firewall configurations, Wi-Fi security protocols, and multi-layered defense strategies.

6. **Accelerate Your Job Search with AI**
   * Leveraging generative AI tools to streamline IT troubleshooting, automate scripts, draft support documentation, and evaluate infrastructure vulnerabilities.

## 🛠️ Key Skills & Competencies Gained
* **Help Desk & Support Operations:** End-to-end incident resolution, customer communication, ticketing workflows, and user intake.
* **Systems Administration:** User provisioning, group policies, access control management, and routine system maintenance.
* **Network Troubleshooting:** Diagnosing local network failures, analyzing TCP/IP configurations, and managing IP addressing.
* **Operating System Fluency:** Configuring and troubleshooting Windows 10/11, macOS, and Linux environments.
* **Command-Line Proficiency:** Executing administrative tasks and automation using Bash and PowerShell.
