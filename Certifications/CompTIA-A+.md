# 📜 CompTIA A+ Certification

* **Credential Provider:** CompTIA
* **Status:** In Progress (Expected: December 2026)

## 🔍 Program & Certification Overview
The **CompTIA A+** is the industry-standard baseline certification for launching an IT career. Recognized widely by employers, it serves as an essential HR filter for entry-level IT support, desktop support, and help desk roles by validating core technical competencies.

## 📚 Core Exam Structure
The certification is divided into two comprehensive exams covering the full scope of technical support responsibilities:

1. **Core 1 (220-1201)**
   * **Mobile Devices:** Laptop hardware, mobile device management (MDM), and smartphone configuration.
   * **Networking:** TCP/IP models, port numbers, Wi-Fi standards, routers, and network troubleshooting.
   * **Hardware:** Motherboards, CPUs, RAM types, power supplies, storage devices, and expansion cards.
   * **Virtualization & Cloud Computing:** Client-side virtualization and cloud service models.
   * **Hardware & Network Troubleshooting:** Resolving physical display, device, and connectivity issues.

2. **Core 2 (220-1202)**
   * **Operating Systems:** Comprehensive administration and troubleshooting for Windows 10/11, macOS, and Linux.
   * **Security:** Physical security, malware mitigation, user authentication, access control policies, and data privacy.
   * **Software Troubleshooting:** Resolving OS boot errors, application failures, and mobile security vulnerabilities.
   * **Operational Procedures:** IT safety, environmental controls, professional communication, and ticketing workflows.

## 🛠️ Key Skills & Competencies Gained
* **Hardware Diagnostics & Maintenance:** Assembling workstations, diagnosing component failures, and maintaining peripheral systems.
* **Operating System Administration:** Managing Windows, macOS, and Linux environments through GUI and command-line interfaces.
* **Networking & Connectivity:** Configuring local networks, addressing IP settings, and resolving connectivity failures.
* **Security Enforcement:** Implementing basic access controls, identifying vulnerabilities, and applying security hardening practices.
* **Service Desk Fundamentals:** Delivering structured incident resolution, documenting troubleshooting steps, and executing user support workflows.
